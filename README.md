# Математические основы защиты информации

Моргун Иван Юрьевич, ФИТ-232. Вариант № 3.

Лабораторные работы по методическим указаниям С. Ю. Белим и С. В. Белима, ОмГТУ, 2023.

Python 3.8 или новее. Сторонние библиотеки не требуются. Команды выполняются из корня репозитория.

| Работа | Запуск |
|---|---|
| 1. Шифр Цезаря | `python3 lab01.py` |
| 2. Криптоанализ аффинного шифра | `python3 lab02.py --step` |
| 3. Модель открытого текста | `python3 lab03.py` |
| 4. RSA | `python3 lab04.py` |
| 5. Криптоанализ RSA | `python3 lab05.py` |
| 6. Методы факторизации | `python3 lab06.py` |
| 7. Дискретный логарифм | `python3 lab07.py` |

Отчёты находятся в папке [Отчёты](Отчёты). Для параметров команд используйте `--help` у работ 1–4 и 6.

В работе 2 отдельные вычисления доступны через `python3 lab02.py inverse`, `congruence` и `system`.
Файл `arithmetic.py` содержит общие арифметические функции.
